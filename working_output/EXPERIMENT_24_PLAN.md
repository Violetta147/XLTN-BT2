# Experiment 24: AMDF competing-minimum confidence gate

- Rollback/accepted baseline before this experiment: `a3b504b` (AMDF + energy gate + median5; EXP23 median7 rejected).
- Source of idea: read-only subagent review after EXP23. Code review confirms `amdf_score` already finds local minima in its lag range but retains only the best minimum; this gate is not currently applied.
- Hypothesis: among frames otherwise predicted voiced, a small margin between the best and second-best local AMDF minima flags ambiguous period choices. Rejecting only the lowest-margin frames can improve F0std MAE while keeping classification loss small.
- Single variable: add a confidence rejection threshold based on `margin = second_lowest_local_minimum_score - best_local_minimum_score`. Keep existing lag search, best-minimum score and lag, pitch/energy thresholds, frame 25 ms, hop 10 ms, and median5 unchanged. Apply only to otherwise voiced predictions. If a frame has fewer than two local minima, leave it unchanged. Never bridge non-voiced frames during median smoothing.
- Training-only selection: outer four-fold LOFO on the four training files. Within each outer training set, use inner three-fold LOFO. For each inner split, fit the existing pitch/energy thresholds on its two inner-training files; compare a no-gate control plus numeric margin cutoffs from quantiles `q ∈ {0, .10, .20, .30, .40, .50}` of margins on their frames predicted voiced; evaluate each on the inner-held-out file. Select by highest mean per-file macro F1; ties by higher balanced accuracy, higher V recall, then fewer rejected frames. Refit the existing thresholds on the three outer-training files; if the no-gate control wins, keep no gate, otherwise recompute that q-quantile cutoff using only those three files' predicted-voiced margins, then apply it to the outer-held-out file. Do not use LAB from a held-out fold for any fitting or selection.
- Keep only if all outer-fold criteria pass versus median5 baseline: mean F0std MAE improves by at least 0.25 Hz; mean F0mean MAE worsens by at most 0.10 Hz; macro F1 and balanced accuracy each decline by at most 0.005; mean V recall declines by at most 0.01; NumF0 drops by no more than 2% in aggregate; FP_SIL total is at most 3; no file's F0mean/F0std MAE worsens by more than 1.0 Hz. Otherwise record the failed result and retain baseline.
- Report per-file and aggregate macro F1, recall V/UV, balanced accuracy, F0mean/F0std MAE, NumF0 and FP_SIL. Confirm baseline parity against EXP14 metrics before comparing candidate. Only four training files are available; LOFO is limited internal evidence, not independent external validation. Do not access TEST or Google Drive.
- Code and execution are separate commits after this preregistration. Record command, environment, input list, and output paths in the result.
